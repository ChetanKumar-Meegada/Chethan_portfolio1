# Chethan Kumar Meegada - Professional Portfolio

This is a professional React.js portfolio showcasing work experience, projects, and certifications.

## Features
- Fully responsive design
- Clean, professional UI
- Sections: Hero, Experience, Projects, Certifications
- Built with React and Lucide-React icons

## Local Development

1. Ensure you have Node.js installed.
2. Place your images in `src/assets/images/`.
3. Run `npm install` to install dependencies.
4. Run `npm start` to view the portfolio at `localhost:3000`.

## Deployment
To push to GitHub:
1. Create a new repository on GitHub.
2. `git remote add origin <your-repo-url>`
3. `git add .`
4. `git commit -m "Initial commit: Portfolio"`
5. `git push -u origin main`
